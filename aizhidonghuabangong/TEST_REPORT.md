## 发现的问题

### 1. 中文编码问题 (低优先级)
- **描述**: 使用 curl 发送中文字符时可能出现编码问题
- **影响**: 仅影响命令行测试，不影响前端正常使用
- **建议**: 前端使用 JavaScript fetch API 发送请求时无此问题

### 2. 订单状态显示 (低优先级)
- **描述**: 使用 Python requests 创建订单时，状态字段显示为乱码 ""
- **原因**: 可能是终端编码问题
- **影响**: 数据库中存储正确，仅显示问题
